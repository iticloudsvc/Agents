# Aegis Forge Fitness

A production-ready gym website built with Flask, HTML5, CSS3, JavaScript, and Three.js for 3D elements.

## Prerequisites
- Python 3.8+

## Installation

1. Clone or download the repository.
2. Open a terminal in the project directory.
3. (Optional) Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```
4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
5. Run the application:
   ```bash
   python app.py
   ```
6. Open your browser and navigate to `http://127.0.0.1:5000`.

## Features
- Fully responsive modern design.
- Interactive 3D background and animated 3D elements using Three.js.
- Complete pages for Pricing, Classes, Schedule, Team, and Contact.
- Frontend AI Chatbot simulation for common queries.
- Smooth page transitions and UI animations.
